# init_files_variables_and_expansions

Scripts sobre archivos de inicialización, variables, expansiones y operaciones de Shell.

## Scripts

### 0-alias

Crea un alias `ls` que ejecuta `rm -f *`.

### 1-hello_you

Muestra un saludo utilizando el nombre del usuario actual.

### 2-path

Agrega `/action` al final de la variable `PATH`.

### 3-paths

Cuenta la cantidad de directorios existentes en la variable `PATH`.

### 4-global_variables

Lista las variables de entorno disponibles.

### 5-local_variables

Lista las variables locales, variables de entorno y funciones del shell.

### 6-create_local_variable

Crea una variable local llamada `BEST` con el valor `School`.

### 7-create_global_variable

Crea una variable de entorno llamada `BEST` con el valor `School`.

### 8-true_knowledge

Suma `128` al valor almacenado en la variable de entorno `TRUEKNOWLEDGE`.

### 9-divide_and_rule

Divide el valor de `POWER` entre el valor de `DIVIDE`.

### 10-love_exponent_breath

Calcula `BREATH` elevado a la potencia `LOVE`.

### 11-binary_to_decimal

Convierte un número almacenado en binario en la variable `BINARY` a decimal.

### 12-combinations

Imprime todas las combinaciones posibles de dos letras minúsculas, excepto `oo`.

### 13-print_float

Imprime el valor de la variable `NUM` con dos decimales.

### 14-decimal_to_hexadecimal

Convierta un número de base 10 a base 16
